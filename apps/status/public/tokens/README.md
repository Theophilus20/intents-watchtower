Token icons for the status app. Each file is named by ticker (btc.png, eth.svg, usdc.svg, usdt.svg, sol.svg, bnb.svg, ltc.svg, near.svg).

Every icon in this folder is embedded into the page at build time (npm run app) and replaces the ticker badge for that token.
SVG, PNG and WebP work; keep each under about 30 KB. Use each project's own published assets and follow their brand guidelines.

btc.png was supplied by the project owner.
